Links de página

Gere um link que abre o portal só com um componente, uma página, uma seção do menu ou uma categoria de componentes. Quem recebe não precisa de código e vê só isso até o link vencer ou ser revogado.

Validade

Links ativos

Os links de página e de entrega que ainda valem. Revogado, o link para de abrir na hora, inclusive para quem já abriu.
