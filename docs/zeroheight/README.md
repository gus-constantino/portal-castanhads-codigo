# `.md` para o zeroheight

Um arquivo por componente, gerado a partir da mesma fonte da doc do playground (`components/<id>/<id>.docs.js`), no template Juntos §11.2 G: 3 tabs (Specs · Style · Guidelines), propriedades em tabela com **Padrão** validado na lib estável e seção de **Acessibilidade**.

- É entrada para a IA do zeroheight (§11.2 B): colar o arquivo e conferir a página gerada com `get-page` (§11.2 I).
- A seção final **"Pendências — não publicar"** fica fora do corpo: remover antes de colar.
- Páginas de **fundação** (ex.: `scale.md`) seguem as seções da própria página do zeroheight, não as 3 tabs dos componentes; `[Imagem: …]` diz o que fazer com cada imagem.
- Texto do time reaproveitado do zeroheight; o que mudou ou foi completado está nas pendências e no `docs/CONFERIR.md`.
